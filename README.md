# Memerchant memes

Animated meme files for [Memerchant](https://github.com/mediacolis), a Shopify app that shows reaction memes when shoppers act. The app loads them from jsDelivr:

```
https://cdn.jsdelivr.net/gh/mediacolis/memerchant-memes@<version>/memes/<file>
```

Releases are tagged (`v1`, `v2`, …) and never changed after tagging, so live stores keep working when new memes are added.
